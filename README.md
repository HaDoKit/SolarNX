# SolarNX

> **Альфа-версия 0.2.1-alpha.** Проект на ранней стадии: возможны ошибки, а настройки и протокол
> могут меняться между версиями. Стабильная работа пока подтверждена только на одной конфигурации —
> см. [Проверенная конфигурация](#проверенная-конфигурация). Что изменилось — в [CHANGELOG.md](CHANGELOG.md).

Стриминг игр с Windows-ПК на Nintendo Switch по локальной сети: картинка и звук идут с компьютера
на консоль, а управление с Joy-Con, Pro Controller и сенсорного экрана — обратно на компьютер.

Проект состоит из двух частей:

- **SolarNX** — приложение для Windows (`SolarNX/`). Запускает игру, захватывает изображение и звук и
  передаёт их на Switch, а нажатия кнопок превращает в виртуальный геймпад.
- **SolarNX для Switch** — homebrew-приложение (`Client/`). Показывает поток и отправляет ввод.

![SolarNX на Switch](docs/images/client/menu.jpg)

## Возможности

- **Steam Big Picture** — весь ваш Steam с геймпада.
- **shadPS4** — эмулятор PlayStation 4, с гироскопом через виртуальный DualShock 4.
- **Своя библиотека игр** — обычные игры (`.exe`), игры Steam, эмуляторы и собственные скрипты запуска,
  с обложками в меню Switch.
- До 4 геймпадов, сенсорный экран Switch работает как касания на ПК.
- Аппаратное кодирование на видеокартах NVIDIA, AMD и Intel (кодировщик выбирается сам; AMD и Intel — экспериментально) и аппаратное декодирование на Switch.
- Кнопка Steam на Switch: **«−» + «+»**. Возврат в меню: удерживать **«−» 3 секунды**.

## Проверенная конфигурация

На этой связке подтверждена стабильная работа версии 0.2.0-alpha. На другом оборудовании SolarNX
тоже должен работать, но пока не проверялся.

| | |
|---|---|
| **ПК** | Windows 11 Pro 24H2 (сборка 26100) |
| Процессор | AMD Ryzen 7 5800X |
| Видеокарта | NVIDIA GeForce RTX 3080, драйвер 610.74 |
| Память | 80 ГБ |
| Сеть ПК | кабель (Ethernet) до роутера |
| FFmpeg | 8.1.2 (идёт в комплекте) |
| **Switch** | Nintendo Switch OLED |
| Сеть Switch | Wi-Fi 5 ГГц |

Если SolarNX работает (или не работает) у вас на другом оборудовании — напишите в
[Issues](https://github.com/HaDoKit/SolarNX/issues), это поможет расширить список.
